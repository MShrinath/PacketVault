Create a Model Armor template named cym-inv-security-template-input. This template will protect incoming user prompts before they are processed by Gemini Enterprise. Your configuration must satisfy the following enterprise security requirements:

Setting	Value
Template ID	cym-inv-security-template-input
Location type	Multi-region
Multi-region	us
Filter version	Stable (recommended)
Modality	Specific modalities > Text
Malicious URL Detection	Enabled
Prompt Injection & Jailbreak Detection	Enabled with High confidence level
Sensitive Data Protection	Enabled with Basic detection type
All content filters	High
Create a second Model Armor template named cym-security-template-output. This template will evaluate and filter model-generated responses before they are returned to end users. Your configuration must satisfy the following enterprise security requirements:

Setting	Value
Template ID	cym-security-template-output
Location type	Multi-region
Multi-region	us
Filter version	Stable (recommended)
Modality	Specific modalities > Text
Malicious URL Detection	Enabled
Prompt Injection & Jailbreak Detection	Disabled
Sensitive Data Protection	Enabled with Basic detection type
All content filters	High
Why use a separate output template? Prompt injection and jailbreak detection are designed to inspect user-supplied prompts. Applying these detections to model outputs can create unnecessary false positives and negatively impact valid generated responses.
Finally, configure the cym-inv-enterprise app to use the newly created Model Armor templates, ensuring you use the right template for user prompts and model response outputs.


By deploying Model Armor, you have implemented a mission-critical security layer that safeguards Cymbal Investments's AI ecosystem while preserving operational efficiency.

This configuration continuously monitors and evaluates both user prompts and model responses, ensuring that AI interactions remain secure, compliant, and trustworthy.

Sensitive financial data, such as credit card numbers and confidential customer information is automatically detected and redacted.
